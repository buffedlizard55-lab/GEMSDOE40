Irregularities flagged

  • IR-40-TLS-01. raw.githubusercontent.com, Dropbox, and jsDelivr failed TLS from this sandbox; GitHub API Accept: application/vnd.github.raw succeeded. Data movement used that path only.
  • IR-40-PROXY-01. Holdout truth is the public catalogue. It cannot reward a genuinely new fault. Reported as a limitation, not as a live score.
  • IR-40-SLOT-01. No DrivenData authentication in this sandbox — we cannot spend a weekly slot or confirm a leaderboard number for this file.
  • IR-40-HASH-01. sample_submission.tif in this repo contains the public catalogue as 1s (60,988 positives), i.e. it is a “predict the known map” template, not an empty canvas. We used it only for CRS/shape/footprint, never as a prediction.
