Irregularities worth reviewing

  • Same SGMC basename, three different rasters. Only the GEMSDOE30 pin reproduces the frozen instrument.
  • The supplied template has positive values despite an all-zero example description. It is used only for grid/footprint.
  • Ambiguous tc/depth band descriptions were not used as physical facts or H4 features.
  • H33’s 216-byte ZIP contains no TIFF; its actual TIFF was used for analysis.
  • History also contains a 110-byte header-only file and a one-pixel demo. They are byte-accounted, not falsely correlated.
  • Two old “NaN-outside” variants actually contain millions of NaNs inside the legal sample footprint. Their all-finite companions establish exact storage equivalence; H4 has no such missing inside pixels.
  • The frozen holdout gate is impossible and its incumbent circular.
