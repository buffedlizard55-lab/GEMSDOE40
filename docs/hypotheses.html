Five candidate geological hypotheses we have not shipped before

Ranked by expected live DTI improvement × inverse implementation cost. Only H40-A is implemented in this repository. Holdout truth is the public catalogue — it cannot reward a genuinely new fault (same limitation as every GEMSDOE proxy).

#HypothesisLayer(s)Physical signature Why it would catch a fault missing from USGS/INGENIOUS How it differs from anything already implemented in prior GEMSDOE repos Expected DTICostStatus
1 H40-A Euler SI=0 depth-KDE rtp (band 2), iso_grav_anom (band 13) Reid et al. 1990 Euler source locations for a fault-like contact (SI = 0), converted to a continuous raster by KDE weighted toward tight, shallow, mutually-consistent clusters. USGS Qfaults / INGENIOUS are surface traces. A near-surface magnetic or density contact can exist without a mapped scarp (blind / buried faults, the geothermal target). Tight shallow Euler clusters are that signature; scattered deep solutions are noise. GEMSDOE28 H38-1 added 200 heat-flow-corroborated Euler dots onto the H19-5 dotted base. GEMSDOE28 H32-1 was “tip Euler” on the same base. This hypothesis never reads that base. It is the KDE of the Euler cloud itself. Unknown live. Catalogue-proxy binary DTI 0.0258 vs |∇RTP| 0.0225 (Δ +0.0032). Off-catalogue by construction for the shipped file. Low (done) IMPLEMENTED and uniqueness-checked. Primary download.
2 H40-B mag–grav Euler concordance only Same Euler clouds, intersection only Pixels where a magnetic SI=0 solution and a gravity SI=0 solution agree within 2.5 px and 35 % relative depth — a real density and susceptibility contact. A dual-physics contact in a basin fill is a structural offset of both magnetisation and density, i.e. a fault, even when it has no Qfaults polyline. Concordance is a boost term in H40-A, not the emission rule. No prior GEMSDOE file shipped concordance-only. Possibly higher credit/pixel, lower recall. Medium-low expected mass. Low (filter existing cloud) Not shipped. Next-session candidate if H40-A is live-scored.
3 H40-C basement-penetrating Euler Euler cloud + depth_to_base_surf (band 15) Shallow Euler solutions sitting on local edges / highs of the conductive-base / basement surface — faults that cut basement and can channel deep heat. Geothermal upflow in the Great Basin is preferentially on basement-rooted normal faults (Faulds & Hinz literature). Qfaults often maps only the Holocene surface strand. No prior GEMSDOE site intersected Euler depths with the official basement-depth band as the emission rule. Medium. Needs a holdout that is not the catalogue. Medium Viable with data already in training_features.tif. Not run.
4 H40-D dilatational stepover Euler Euler cloud + geod_dilaterate (band 8) Euler clusters inside positive dilatation (area-increase) at fault stepovers / tips — the structural setting of most Great Basin geothermal fields. Qfaults draws throughgoing traces and under-represents stepover complexity and newly broken relay ramps. Prior strain-rate work (GEMSDOE20 wing-crack, GEMSDOE32 H32b transtensional swarm) did not gate Euler depths on dilatation. Medium. Literature-backed (Faulds, Hinz, Coolbaugh). Medium Viable with existing bands. Not run.
5 H40-E conductive-base breach Euler + cond_surf (17) + depth_to_base_surf (15) Local holes in the clay cap (shallow conductor) aligned with Euler contacts = hydrothermal upflow. Clay caps are an MT / conductivity signature, not a Qfaults polyline. GEMSDOE32 H32c already tried an MT-claycap addition on the H19-5 base. A breach detector that is Euler-gated and not added onto H19-5 has not been shipped. Lower. H32c did not beat the dotted incumbent live. Medium Do not spend a slot until H40-A is scored. External MT 3-D cubes are not required — band 17 is already in the stack.

Promotion rule used for H40-A

Preregistered in this session, not after seeing live scores (there are none):

  • Uniqueness: Pearson < 0.85 and Jaccard < 0.50 vs every prior TIF in ref/. PASS (worst Pearson 0.007, worst Jaccard 0.005 vs H33-2-B2).
  • Not gradient thresholding: same-count binary DTI of Euler cores vs |∇RTP| on the public catalogue, 4-fold not required for this contrast because Euler is unsupervised. PASS (0.0258 vs 0.0225, Δ +0.0032).
  • Zero catalogue leakage in the shipped file. PASS (0 pixels).
  • Legal GeoTIFF. PASS (see home-page receipt).

We do not promote on catalogue-proxy DTI magnitude. A high catalogue DTI is the wrong objective for a hidden-fault contest (GEMSDOE32 measured this disagreement explicitly). H40-A is 98.4 % off-catalogue before masking; after the 2 px buffer it is 100 % off-catalogue.

What would be needed that we do not have

No candidate above requires new external data. All five run on the official 19-band GeoTIFF already in data/training_features.tif (sha256 4371c82e…). A live DrivenData slot is required to know whether H40-A beats 0.2778; that is a process limitation, not a data limitation.
