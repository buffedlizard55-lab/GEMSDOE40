Scientific method

Euler depth deconvolution + weighted-cloud KDE

H7 estimates potential-field source locations/depths from RTP, then projects a gravity-context-weighted 3-D solution cloud. It is not gradient thresholding. Contact locations are not automatically faults, geothermal conduits, or productive resources.
