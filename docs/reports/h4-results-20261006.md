## How it was generated

H4 solves the Reid SI=0 contact equation with arbitrary offset A, using TMI and a local top-edge approximation to the first vertical gravity derivative. East/north/down derivatives are consistent; window coordinates are centered; identifiable rank is recorded. The point cloud is filtered by residual, conditional depth error, position and depth constraints, then weighted by shallow depth and cross-window local depth consistency. Weighted KDEs are fused continuously and exact known pixels masked; no prior output or proxy truth enters generation.

Effective depths are relative to a reference observation plane, not verified depths below terrain.
