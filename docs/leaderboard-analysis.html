What can be said about H33-2-B2

The GEMSDOE32 project page describes H33-2-B2 as a 37,654-pixel candidate, gives a projected 0.2747, and explicitly marks the artifact UNSCORED. The value is a model projection from that project, not an official DrivenData score. The official row's 0.2778 is independently visible but is attached only to the participant account and its best among multiple submissions.

The numerical proximity of 0.2747 and 0.2778 is not evidence of identity. Without a timestamped official submission receipt or a file hash exposed by the organizer, no TIFF-to-score association is established. The honest record therefore keeps all three facts separate: (1) H33-2-B2 is projected at 0.2747; (2) that project labels it unscored; (3) the account row reports 0.2778 without file attribution.

Do not invert a public score into an undocumented TIFF

The published competition metric is a distance-weighted Tversky index; the official task page describes the relevant score and output format. Reconstructing a candidate's score from a public account row would require the exact submitted file, exact label split, exact preprocessing, and official receipt. A proxy, a local shadow metric, a projected score, and a displayed best-account value do not supply those missing facts.

Accordingly, this repository records no official score for H7, H2-B, H40-4, or H33-2-B2. It does not claim that any one of those files earned the 0.2778 account row. H7 remains research-only because its own frozen proxy gate failed, regardless of public-board comparisons.
