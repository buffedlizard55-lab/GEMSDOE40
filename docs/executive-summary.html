Executive summary — how to make a submission

5 STEPS · NO MANUAL GIS

The file is already built. You only upload it.

1. Download GEMSDOE40-submission.tif

Step-by-step (DrivenData portal)

  1. Download GEMSDOE40-submission.tif (or the .zip of the same file).
  2. Open the competition submit page: https://www.drivendata.org/competitions/306/competition-doe-gems/submissions/ (login required).
  3. Choose the downloaded file under File to submit. The portal accepts a single-band GeoTIFF or a zip containing one GeoTIFF.
  4. Paste the note below into Note (optional).
  5. Submit. If the portal says Predicted values must be in range [0, 1], you uploaded the wrong file — this one cannot produce that error (every one of 12,279,160 cells is finite and in [0, 1], nodata is unset). Use the zeros file, not a NaN-outside file, if a validator change starts treating NaN as out of range.

Name and note to paste

Name: GEMSDOE40-euler-si0-depthkde

Note (106 / 200 characters):

GEMSDOE40 Euler SI=0 depth-KDE | RTP+isograv win8/12, 45784 px, 0 on cat, bin Δvs|∇RTP| +0.0032 | 5bc279cd

Why the portal previously said “Predicted values must be in range [0, 1]”

Two different failures produce the same message. Both are measured in this repository:

  • Mechanism 1 — the float32 sentinel. training_features.tif uses −3.4028234663852886e+38 as nodata. Writing those through unchanged puts values outside [0, 1].
  • Mechanism 2 — a nodata tag that is not in [0, 1]. A raster whose nodata tag is that sentinel, or whose cells are NaN, can be rejected if the validator does not special-case them.

The primary download is written all-finite, nodata=None, every cell in [0, 1]. That is the belt-and-braces file. A NaN-outside twin (the sample-submission convention) is offered as a fallback only.

What the file is

  • Method: 3-D Euler deconvolution (Reid et al., Geophysics 1990) at structural index 0 (fault-like contact) on RTP magnetics and isostatic gravity.
  • Output: kernel-density estimate of shallow, tight, mutually-consistent solution clusters, normalised to [0, 1].
  • Catalogue cells (USGS / INGENIOUS labels) plus a 200 m buffer are 0 — the hidden test is faults not in that catalogue.
  • Not a copy of GEMSDOE32 H33-2-B2 (Pearson 0.007, Jaccard 0.005).

What this site will not do

  • It cannot log into DrivenData, so it cannot press Submit for you and cannot auto-download a fresh training_features.tif from the competition data tab.
  • It cannot see the hidden expert traces, so it cannot report a live DTI. Any number on this site that is not from the public leaderboard is a claim or a holdout proxy, labelled as such.
