How a submission is entered in this competition

These are the mechanics, not permission to submit H8. A slot should only be spent on a candidate that has passed a registered, independent validation gate. H8 has not.

  1. Open the official competition in your own account; confirm eligibility, enrollment and current rules. Never put passwords or tokens in this repository.
  2. Download the exact approved .tif (or the .zip containing one) and compare its SHA-256 with its receipt. Do not upload a saved HTML page.
  3. Click New submission. In File to submit choose the GeoTIFF (or the single-TIFF zip). It must match the sample's CRS (EPSG:32611), shape (3,730×3,292) and geotransform (100, 0, 243350, 0, −100, 4508550) — this file does.
  4. Paste the short note into Note (optional) so submissions stay distinguishable later (e.g. the 152-character note above).
  5. Submit, then keep the server's validation response. An account's leaderboard row is not a receipt for a particular file.
  6. Respect the official rules PDF, including weekly limits and the single-final-submission choice across prize rounds. This pipeline never performs a DrivenData upload itself.

Preventing "Predicted values must be in range [0, 1]"

That portal error has two known causes, and this project has measured both in earlier sessions: values outside [0,1], or a nodata tag holding a large negative sentinel (e.g. −3.4028235e+38 copied from the feature stack). The H8 downloads defend against both:

  • Portal-safe twin (recommended): every one of the 12,279,160 pixels is finite; all 5,167,373 footprint values lie in [0,1]; all 7,111,787 outside pixels are exactly 0; no nodata tag is written at all.
  • NaN-outside research twin: identical footprint values; NaN only outside, matching the sample's own NaN convention — the format the written rules describe.
  • The feature stack's −3.4028235e+38 sentinel is detected with a magnitude mask and is never copied into any prediction.

A local pass is not a guarantee about an unknown server-side validator; if an authorized upload ever fails, retain the exact bytes and error text for diagnosis.
